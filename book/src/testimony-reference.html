This appendix is a one-page reference for how testimony.explain renders truths. The format is defined by the expected outputs in the repository's examples/ directory. Rows marked proposed are not yet backed by an example and may change.

Layout

  • The first line is verity or falsity.
  • Testimony follows as a tree, one node per line, with each level indented two spaces further than its parent.
  • Testimony includes only what decided the answer. Short-circuited parts never appear.

Nodes

SourceAs a verityAs a falsityStatus
Comparison a op b src: a op b src: a op' b, where op' is the opposite relation settled
p and q all of: with every part beneath (chains flattened) testimony of the first failing part settled
p or q testimony of the first holding part none of: with every part beneath settled
not p not: with p's testimony beneath proposed
p because msg witnessed: msg with p's testimony beneath refuted: msg with p's testimony beneath settled
forall x in xs, body all N elements of xs satisfy body counterexample: x = v (xs[i]) with the body's refutation beneath settled
exists x in xs, body witness: x = v (xs[i]) with the body's witness beneath no element of xs satisfies body verity settled; falsity proposed
Literal verity / falsity literal; under because, nothing (the message is the whole testimony) under because settled; bare proposed
Lifted Python bool call(args) returned True / returned False proposed

Positions

Quantifier positions are written as an index into the collection, (primes[4]), when the collection is a simple name. For other iterables it is proposed to write (element 4).

A complete example

'grace_hopper': falsity
  refuted: 'grace_hopper' is alphanumeric
    '_' at index 5 is not alphanumeric

Here, a because wraps a standard library predicate whose own refutation names the offending character. See Section 3.6 for the full program.
