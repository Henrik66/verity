The complete grammar of Verity, in the notation of About These Docs. [[proposed]] Token classes come from Section 2. Rules marked "as in Python" abbreviate Python's grammar for the same construct.

Modules and statements

file          ::= statement* ENDMARKER
statement     ::= simple_stmt | compound_stmt
simple_stmt   ::= small_stmt (";" small_stmt)* [";"] NEWLINE
small_stmt    ::= expression_stmt | assign_stmt | return_stmt | import_stmt
                | raise_stmt | assert_stmt | del_stmt
                | "pass" | "break" | "continue"
                | "global" NAME ("," NAME)* | "nonlocal" NAME ("," NAME)*
expression_stmt ::= expression_list
assign_stmt   ::= (target_list "=")+ expression_list
                | target augassign expression_list
return_stmt   ::= "return" [expression_list]
raise_stmt    ::= "raise" [expression ["from" expression]]
assert_stmt   ::= "assert" expression ["," expression]
del_stmt      ::= "del" target_list
import_stmt   ::= (* as in Python *)

compound_stmt ::= funcdef | data_def | if_stmt | while_stmt | for_stmt
                | match_stmt | try_stmt | with_stmt
block         ::= simple_stmt | NEWLINE INDENT statement+ DEDENT
if_stmt       ::= "if" expression ":" block ("elif" expression ":" block)* ["else" ":" block]
while_stmt    ::= "while" expression ":" block ["else" ":" block]
for_stmt      ::= "for" target_list "in" expression_list ":" block ["else" ":" block]
try_stmt      ::= (* as in Python *)
with_stmt     ::= (* as in Python *)

Definitions

funcdef       ::= ["addpattern"] "def" NAME "(" [param_list] ")" ["->" expression] body
body          ::= "=" expression NEWLINE | ":" block
param_list    ::= param ("," param)* [","]
param         ::= NAME ["=" expression] | "*" NAME | "**" NAME | pattern
data_def      ::= "data" NAME "(" [NAME ("," NAME)* [","]] ")" NEWLINE

Pattern matching

match_stmt    ::= "match" expression ":" NEWLINE INDENT case_block+ DEDENT
case_block    ::= "case" pattern ["if" expression] ":" block
pattern       ::= or_pattern ["as" NAME]
or_pattern    ::= closed_pattern ("|" closed_pattern)*
closed_pattern ::= literal_pattern | NAME | "_" | class_pattern
                | sequence_pattern | "(" pattern ")"
literal_pattern ::= ["-"] NUMBER | STRING+ | "None" | "verity" | "falsity"
class_pattern ::= dotted_name "(" [pattern ("," pattern)* [","]] ")"
sequence_pattern ::= "[" [pattern ("," pattern)* [","]] "]"
dotted_name   ::= NAME ("." NAME)*

Expressions

expression_list ::= expression ("," expression)* [","]
expression    ::= quantifier | lambda | conditional
quantifier    ::= ("forall" | "exists") NAME "in" or_test "," expression
lambda        ::= lambda_params "->" expression
lambda_params ::= NAME | "(" [NAME ("," NAME)* [","]] ")"
conditional   ::= or_test ["if" or_test "else" expression]

or_test       ::= and_test ("or" and_test)*
and_test      ::= because_test ("and" because_test)*
because_test  ::= not_test ["because" not_test]
not_test      ::= "not" not_test | comparison
comparison    ::= pipe (comp_op pipe)*
comp_op       ::= "==" | "!=" | "<" | ">" | "<=" | ">="
                | "in" | "not" "in" | "is" | "is" "not"
pipe          ::= compose ("|>" compose)*
compose       ::= bit_or ("..>" bit_or)*
bit_or        ::= bit_xor ("|" bit_xor)*
bit_xor       ::= bit_and ("^" bit_and)*
bit_and       ::= shift ("&" shift)*
shift         ::= arith (("<<" | ">>") arith)*
arith         ::= term (("+" | "-") term)*
term          ::= factor (("*" | "@" | "/" | "//" | "%") factor)*
factor        ::= ("+" | "-" | "~") factor | power
power         ::= primary ["**" factor]

primary       ::= atom trailer*
trailer       ::= "(" [arguments] ")" | "$" "(" [arguments] ")"
                | "[" subscripts "]" | "." NAME
arguments     ::= argument ("," argument)* [","]
argument      ::= expression | NAME "=" expression | "*" expression | "**" expression
subscripts    ::= (* as in Python *)
atom          ::= NAME | NUMBER | STRING+ | "verity" | "falsity" | "None"
                | "(" [expression_list] ")" | "(" expression comp_for ")"
                | "[" [expression_list | expression comp_for] "]"
                | "{" [dict_or_set] "}"
comp_for      ::= (* as in Python *)
dict_or_set   ::= (* as in Python *)

Notes

  • In lambda, the parser distinguishes NAME "->" and "(" … ")" "->" from ordinary parenthesized expressions by looking ahead to the arrow.
  • In a call, f(forall x in xs, p, y) passes two arguments: the quantifier (body p) and y. The body is an expression, not an expression_list, so it stops at the next comma.
  • because_test permits at most one because (Section 4.9).
  • Chained comparisons are syntactically accepted, but their semantics are open (Section 4.7).
