This section specifies the testimony carried by truths: the node kinds, how each operator constructs them, how testimony.explain renders them, and when the compiler may omit them.

Construction rules

Below, T(e) is the testimony of a truth e, and V(e) its value.

Comparison

For a op b whose Python result r is a bool: V = r, and T is comparison(src, a, rel, b), where src is the exact source text of the comparison, and rel is op when r is true and negate(op) otherwise:

negate(op)!===>=><=<not inis not

Negation

V(not p) = ¬V(p) and T(not p) = not(T(p)).

Conjunction

For p₁ and p₂ and … and pₙ, evaluated left to right:

  • If some pᵢ is a falsity, let k be the first such index. Then V = falsity and T = T(pₖ). The operands after pₖ are not evaluated.
  • Otherwise, V = verity and T = all(T(p₁), …, T(pₙ)). If a T(pᵢ) is itself an all node produced directly by and, its children are spliced in place (flattening). A because node is never flattened.

Disjunction

For p₁ or … or pₙ:

  • If some pᵢ is a verity, let k be the first. Then V = verity and T = T(pₖ).
  • Otherwise, V = falsity and T = none(T(p₁), …, T(pₙ)), flattened analogously.

because

V(p because m) = V(p). T = because(str(m), V(p), T(p)), except that when T(p) is literal the node has no child.

Quantifiers

For forall x in xs, body, iterate over the elements v₀, v₁, … of xs:

  • At the first index i where body[x := vᵢ] is a falsity b: V = falsity, T = counterexample(x, vᵢ, pos(i), T(b)).
  • If none: V = verity, T = universal(n, src(xs), src(body)), where n is the number of elements.

For exists, exchange verity and falsity: the first verity b gives witness(x, vᵢ, pos(i), T(b)), and exhaustion gives no-element(src(xs), src(body)).

pos(i) is rendered xs[i] when the iterable expression is a plain name. [[settled]] Otherwise, it is rendered element i. [[proposed]]

Rendering

testimony.explain(t) returns a string of one or more lines, joined by \n, without a trailing newline: [[settled]]

  1. The first line is verity or falsity.
  2. The root node of T(t) is rendered at depth 1. A node at depth d is one line indented by 2·d spaces, followed by its children at depth d + 1, in order.
  3. Values are rendered with Python's repr(). Source text is reproduced exactly as written.

Conformance example

import string_ops
from testimony import explain

def valid_username(name) =
    (len(name) >= 3 because f"{name!r} has at least 3 characters")
    and (len(name) <= 16 because f"{name!r} has at most 16 characters")
    and (string_ops.is_alnum(name) because f"{name!r} is alphanumeric")

for name in ["ada", "al", "grace_hopper"]:
    print(f"{name!r}: {explain(valid_username(name))}")

'ada': verity
  all of:
    witnessed: 'ada' has at least 3 characters
      len(name) >= 3: 3 >= 3
    witnessed: 'ada' has at most 16 characters
      len(name) <= 16: 3 <= 16
    witnessed: 'ada' is alphanumeric
      every character of 'ada' is alphanumeric
'al': falsity
  refuted: 'al' has at least 3 characters
    len(name) >= 3: 2 < 3
'grace_hopper': falsity
  refuted: 'grace_hopper' is alphanumeric
    '_' at index 5 is not alphanumeric

This is examples/validate.ity. The three because nodes in the first case are not flattened into each other, but the all node of the two-level and chain is.

Observation

The testimony of a truth-valued expression is observed if the truth can reach any of the following: [[proposed]]

  • an argument to testimony.explain or any other function of the testimony module;
  • an attribute access on the truth object;
  • a return statement, yield, or the value of a short-form def;
  • a variable, attribute, container element or data field that is itself used other than as a condition;
  • an argument to any function that the compiler cannot see into, including all Python functions;
  • the operand of because, and, or or not, or the body of a quantifier, whose result is itself observed.

A truth whose only use is as the condition of if, elif or while, the test of a conditional expression, or a case guard is not observed.

Erasure

For an expression whose testimony is not observed, the compiler may emit code that computes only the truth value, for example a plain Python comparison, instead of constructing testimony. [[settled]] An erased expression must: [[proposed]]

  • evaluate exactly the same subexpressions, in the same order, as the unerased form, including short-circuiting;
  • produce the same truth value;
  • not evaluate the messages of because, which are evaluated only when testimony is observed (Section 4.9).

Erasure is an optimization. A program's output must be identical with erasure enabled or disabled. When the analysis is uncertain, the compiler must keep testimony.

def clamp(x) = 0 if x < 0 else 10 if x > 10 else x

def clamp(x):
    return 0 if x < 0 else 10 if x > 10 else x

Cost model

[[proposed]] Implementations should meet these bounds:

  • An erased truth costs the same as the equivalent Python boolean expression.
  • An observed comparison allocates one node and holds references to its two operands.
  • A quantifier's testimony holds only the deciding element (or, for universal, a count). Its size does not grow with the length of the iterable.
  • A conjunction's or disjunction's testimony grows with the number of operands, not with the number of evaluations of an enclosing loop.
