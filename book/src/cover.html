Checks that explain themselves

The reference documentation for Verity, Python whose truth values explain themselves, to people and to agents: its syntax, semantics, testimony model, machine interface, Python interoperability, standard library and compiler. Also available as plain text: llms.txt, verity.txt.

Status

Verity is in early design and no implementation exists yet. This document specifies the language the implementation is being built to accept. Rules are marked [[settled]], [[proposed]] or [[open]]. See About These Docs.
