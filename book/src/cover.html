The reference documentation for Verity, a functional language that compiles to Python and whose booleans testify: its syntax, semantics, testimony model, Python interoperability, standard library and compiler.

Status

Verity is in early design and no implementation exists yet. This document specifies the language the implementation is being built to accept. Rules are marked [[settled]], [[proposed]] or [[open]]. See About These Docs.
