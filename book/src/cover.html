This edition describes a language that is still being built

Verity is in early design. No compiler exists yet, so none of the programs in this book run today. Every example shows the intended behavior, and the output blocks are the targets the implementation is being built to match. Boxes like this one mark design notes: questions that are still open and proposals not yet adopted.

About this book

Most programming languages hand you a boolean and walk away. When a check fails, you get False and a hunt for the reason. Verity tries something different. Its truth values, verity and falsity, carry testimony: a verity carries a witness for why it holds, and a falsity carries a refutation for why it doesn't. This book teaches the language from its first expressions up to the compiler pass that removes testimony nobody looks at.

Along the way it covers the functional toolkit Verity borrows from Coconut: lambdas, pipes, partial application, composition, algebraic data types and pattern matching. It also covers how all of it compiles to ordinary Python, so the Python ecosystem stays at hand.

What's inside

  • Preface: who the book is for, conventions and exercises.
  • 1. Introduction: what Verity is, a first program and how it runs.
  • 2. The Basics: values, definitions, truth values, control flow and imports.
  • 3. Truth and Testimony: witnesses and refutations, the logical operators, and because.
  • 4. Quantifiers: forall, exists, counterexamples and witnesses.
  • 5. Functions and Pipelines: lambdas, pipes, partial application and composition.
  • 6. Data and Patterns: data types, match and addpattern.
  • 7. Living with Python: the rules at the boundary between Verity and Python.
  • 8. Under the Hood: the Rust compiler, the runtime and testimony erasure.
  • Appendices: a testimony format reference and a glossary.
