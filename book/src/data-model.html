Every value in a running Verity program is a Python object. This section describes the objects Verity adds: truths, testimony, reasons and secrets.

Objects

Verity has no object model of its own. Integers, strings, lists, functions, classes, data classes, modules and all other values are the corresponding Python objects, with Python's identity, type and mutability rules. [[settled]]

The truth type

truth is the type of truth values. [[settled]]

  • It has exactly two constructors: verity (true) and falsity (false).
  • Every truth carries a testimony tree (Section 5). A verity's testimony is called its witness, and a falsity's its refutation.
  • At run time, truths are instances of the runtime class testimony.Truth (Section 8.2).
  • Truths are immutable.
  • bool(t) is True for a verity and False for a falsity. Truths are accepted anywhere Python accepts a condition.
  • Equality and hashing consider only the truth value, never the testimony. Two verities with different witnesses are equal, and a truth equals the bool with the same value.
  • str(t) and repr(t) are "verity" or "falsity". Testimony is shown only by explain and to_json.
  • truth is not a subclass of Python's bool or int, so arithmetic on truths raises TypeError.

Testimony

A testimony is a finite tree of immutable nodes. Each node has a kind, a truth value, the data for that kind (source text, captured values, a claim, a position) and an ordered tuple of children. The node kinds, how they are constructed and how they are rendered are specified in Section 5. [[settled]]

Nodes hold repr strings of the values they mention, captured when the node is built, not references to the values. Testimony therefore does not keep large objects alive and does not change when a value is mutated (Section 5.8). [[settled]]

Reasons

A Reason is an immutable value with three attributes: id, a dotted identifier; message, the claim; and hint, a string or None. It is built by testimony.reason(id, message, hint=None) and used as the right operand of because (Section 5.3). [[settled]]

Secrets

A Secret wraps one value. It compares and hashes like that value, renders as <secret>, and supports no other operations. testimony.reveal(s) returns the wrapped value (Section 5.7). [[settled]]

TestimonyError

testimony.TestimonyError is a subclass of Python's AssertionError. It is raised by a failing assert (Section 6.2) and by Truth.expect(). Its attribute truth holds the falsity, and str(e) is explain(e.truth). [[settled]]
