The standard library consists of modules that are always importable from Verity. Their functions return truths whose testimony is meaningful at the library's level, not the level of its implementation. Module and function names are snake_case. [[settled]]

Module testimony

Functions for working with truths and their testimony.

explain(t: truth) -> str [[settled]]

Return the rendering of t defined in Section 5.3: "verity" or "falsity" on the first line, followed by the indented testimony tree, without a trailing newline. A Python bool argument is lifted first (Section 7.2).

from testimony import explain
print(explain(2 + 2 == 5))

falsity
  2 + 2 == 5: 4 != 5
to_bool(t: truth) -> bool [[settled]]

Return True if t is a verity and False if it is a falsity, discarding testimony. Use it when passing truth values to Python code that requires a bool (Section 7.3).

as_dict(t: truth) -> dict [[proposed]]

Return the testimony as a JSON-serializable structure, for logging and tooling: {"value": "falsity", "testimony": node}, where each node is {"kind": str, "line": str, "children": [node, ...]} and line is the node's rendered line without indentation. Values appear only in their repr() form.

Class Truth

The runtime class of truths. It is not normally named in Verity source: values are created by literals, comparisons and the operators in Section 4.

bool(t) [[settled]]

True for a verity, False for a falsity.

str(t), repr(t) [[proposed]]

"verity" or "falsity".

t == u, hash(t) [[proposed]]

Compare and hash by truth value only.

t.testimony [[proposed]]

The root testimony node. Nodes are read-only objects with attributes kind (one of the kinds in Section 5.1), line (the rendered line) and children (a tuple of nodes). Accessing this attribute counts as observing the testimony.

Module string_ops

String predicates with character-level testimony.

is_alnum(s: str) -> truth [[settled]]

A verity if s is non-empty and every character is alphanumeric in the sense of Python's str.isalnum. Testimony, as a text node:

  • verity: every character of {repr(s)} is alphanumeric
  • falsity at the first offending character c at index i: {repr(c)} at index {i} is not alphanumeric
  • falsity for the empty string: '' is empty [[proposed]]
import string_ops
from testimony import explain
string_ops.is_alnum("grace_hopper") |> explain |> print

falsity
  '_' at index 5 is not alphanumeric

Further string_ops functions are [[open]]. Testifying counterparts of the str.is* predicates are the expected first additions.
