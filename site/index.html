Pl. III · Cur testimonium

Why testifying booleans?

  • Falsities explain themselves

    A failed check carries its refutation: which comparison failed and what the values were. You don't have to add a debugger session or a print statement after the fact.

  • Testimony composes

    and, or, not, comparisons, forall and exists assemble testimony for you. forall hands you the counterexample; exists hands you the witness.

  • Say it in your own words

    because attaches a human-readable claim, so a validation rule reads like the error message it will produce.

  • Free when nobody asks

    The compiler erases testimony that is never looked at, so an ordinary if costs what it always did.

  • Still Python underneath

    Verity compiles to plain Python, so the standard library, numpy and the rest of PyPI come along.
