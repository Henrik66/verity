Same question. Two very different answers.

Is every prime odd? Python can only tell you no. Verity tells you no, then hands you the prime that proves it.

check.pyPython
primes = [2, 3, 5, 7, 11, 13]

print(all(p % 2 == 1 for p in primes))
False
check.ityVerity
primes = [2, 3, 5, 7, 11, 13]

(forall p in primes, p % 2 == 1) |> explain |> print
falsity counterexample: p = 2 (primes[0]) p % 2 == 1: 0 != 1

Python: one bit. Something failed, somewhere.

Verity: the failing element, where it sits, and the values it produced.
