NAME

verity-testimony - the evidence carried by truth values

SYNOPSIS

a op b
p and q p or q not p
p because message
forall x in xs, body exists x in xs, body
testimony.explain(t)

DESCRIPTION

Every truth carries a testimony: a tree of nodes recording why it holds. A verity carries a witness and a falsity a refutation. The operators above compose testimony automatically; explain renders it. The compiler may omit testimony that is never observed (see ERASURE).

NODE KINDS

comparison [settled]
From a op b. Records the source text and both values. No children.
all, none [settled]
A verity from and, a falsity from or. One child per operand.
because [settled]
From p because message. One child, T(p), unless p is a literal.
counterexample, witness [settled]
The first element that decided forall or exists, with its position.
not, lifted [proposed]
Negation; a Python bool used as a truth.

CONJUNCTION

Operands of p1 and ... and pn are evaluated left to right. At the first falsity pk the result is a falsity whose testimony is T(pk); later operands are not evaluated. If every operand is a verity, the testimony is all(T(p1), ..., T(pn)), with directly nested all nodes spliced in place. [settled]

EXAMPLES

From examples/validate.ity:

def valid_username(name) =
    (len(name) >= 3 because f"{name!r} has at least 3 characters")
    and (len(name) <= 16 because f"{name!r} has at most 16 characters")
    and (string_ops.is_alnum(name) because f"{name!r} is alphanumeric")
$ verity run validate.ity
falsity
  refuted: 'al' has at least 3 characters
    len(name) >= 3: 2 < 3
