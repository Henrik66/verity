5. Testimony Semantics

Verity Programming, section 5 of 10. H. Gombos, P. Balakrishnan.
Status: draft reference for verity 0.0. Prev [1] Next [2] Index [3]

This section specifies the testimony carried by truths: the node kinds, how each operator constructs them, how testimony.explain renders them, and when the compiler may omit them.

5.1 Node kinds

A testimony is a tree of nodes. Proposed kinds are marked (P).

+----------------+---------------------+--------------------+
| kind           | produced by         | children           |
+----------------+---------------------+--------------------+
| comparison     | a op b              | none               |
| all            | verity from and     | one per conjunct   |
| none           | falsity from or     | one per disjunct   |
| not (P)        | not p               | T(p)               |
| because        | p because m         | T(p)               |
| counterexample | falsity from forall | body's refutation  |
| witness        | verity from exists  | body's witness     |
| lifted (P)     | a Python bool       | none               |
+----------------+---------------------+--------------------+

5.2 Construction: conjunction

For p1 and ... and pn, evaluated left to right:

  (a) If some pi is a falsity, let k be the first such index.
      Then V = falsity and T = T(pk). Later operands are not
      evaluated.

  (b) Otherwise V = verity and T = all(T(p1), ..., T(pn)).
      Nested all nodes from and are spliced in place; a because
      node is never flattened.

5.3 Rendering

From examples/validate.ity [4]:

def valid_username(name) =
    (len(name) >= 3
        because f"{name!r} has at least 3 characters")
    and (len(name) <= 16
        because f"{name!r} has at most 16 characters")
    and (string_ops.is_alnum(name)
        because f"{name!r} is alphanumeric")

$ verity run validate.ity          as a tree:
falsity
  refuted: 'al' has at least 3     falsity
    characters                     `-- because  'al' has at least 3
    len(name) >= 3: 2 < 3              |        characters
                                       `-- comparison
                                             len(name) >= 3: 2 < 3

The first line is verity or falsity. A node at depth d is one line indented by 2*d spaces, then its children at depth d + 1.
