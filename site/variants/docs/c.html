5 Testimony Semantics

1

This section specifies the testimony carried by truths: the node kinds, how each operator constructs them, how testimony.explain renders them, and when the compiler may omit them.

5.1 Node kinds

1

A testimony is a tree of nodes. The kinds are given in Table 5.1.

KindProduced byChildren
comparisona op bnone
allverity from andone per conjunct
nonefalsity from orone per disjunct
notnot pT(p)
becausep because mT(p), unless literal
counterexamplefalsity from forallbody's refutation
witnessverity from existsbody's witness
lifteda Python boolnone

5.2 Construction rules

1

Below, T(e) is the testimony of a truth e, and V(e) its value.

2

For p1 and ... and pn, evaluated left to right: if some pi is a falsity, let k be the first such index. Then V = falsity and T = T(pk), and the operands after pk are not evaluated.

3

Otherwise V = verity and T = all(T(p1), ..., T(pn)). A child that is itself an all node produced directly by and is spliced in place. A because node is never flattened.

4

pos(i) is rendered "element i" when the iterable expression is not a plain name.

5

NOTE: rule 2 reports only the first failure. An accumulating conjunction is under discussion.

5.3 Rendering

1

EXAMPLE (examples/validate.ity):

def valid_username(name) =
    (len(name) >= 3 because f"{name!r} has at least 3 characters")
    and (len(name) <= 16 because f"{name!r} has at most 16 characters")
    and (string_ops.is_alnum(name) because f"{name!r} is alphanumeric")
falsity
  refuted: 'al' has at least 3 characters
    len(name) >= 3: 2 < 3
2

The first line is verity or falsity. A node at depth d is one line indented by 2d spaces, followed by its children at depth d + 1.
