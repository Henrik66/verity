Section 5

Testimony Semantics

Henrik Gombos · Pranav Balakrishnan · draft for verity 0.0

SummaryThis section specifies the testimony carried by truths: the node kinds, how each operator constructs them, how testimony.explain renders them, and when the compiler may omit them.

5.1Node kinds

Definition 5.1 (Testimony). A testimony is a finite ordered tree whose nodes are labelled with a kind and its data. The testimony of a truth e is written T(e), and its value V(e) ∈ {verity, falsity}.

5.2Construction

We write P for p1 and … and pn. Conjunction is evaluated left to right and short-circuits on the first falsity.

V(pk) = falsity    ∀i<k. V(pi) = verityV(P) = falsity    T(P) = T(pk)And-F ∀i. V(pi) = verityT(P) = all(T(p1), …, T(pn))And-T T(p) = tT(p because m) = because(m, V(p), t)Because
2 In [And-F] the operands pk+1 … pn are not evaluated, so they contribute no testimony. [And-T] flattens directly nested all nodes; a because node is never flattened.

5.3Rendering

explain(t) prints V(t), then each node of T(t) on its own line, indented by 2d spaces at depth d.

def valid_username(name) =
    (len(name) >= 3 because f"{name!r} has at least 3 characters")
    and (len(name) <= 16 because f"{name!r} has at most 16 characters")
    and (string_ops.is_alnum(name) because f"{name!r} is alphanumeric")
falsity
  refuted: 'al' has at least 3 characters
    len(name) >= 3: 2 < 3

Figure 5.1. explain(valid_username("al")). [And-F] applies with k = 1, then [Because].
