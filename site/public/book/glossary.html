Appendix BGlossary

addpattern
Keyword prefix of def that appends a case to an existing pattern-matching function. Section 6.3.
because
Operator attaching a claim to a truth: p because m. Renders as witnessed: m or refuted: m. Section 4.9.
conformance suite
The programs in examples/ and their expected outputs. They define testimony rendering. Section 10.7.
counterexample
The testimony node of a falsity produced by forall: the first element that refuted the body. Section 5.2.
data value
An instance of a class declared with data: immutable, with structural equality. Section 3.4.
erasure
Compiling a truth-valued expression whose testimony is not observed to code that computes only its truth value. Section 5.5.
falsity
The false constructor of truth. Its testimony is a refutation.
lifting
Converting a Python bool into a truth with a lifted testimony node. Section 7.2.
MatchError
Exception raised when no case of a pattern-matching function matches its arguments.
observed
Said of testimony that can reach code able to inspect it. Unobserved testimony may be erased. Section 5.4.
partial application
f$(args): a callable with some leading arguments of f fixed. Section 4.3.
pattern-matching function
A function defined with pattern parameters, consisting of ordered cases. Section 6.3.
pipe
x |> f, equivalent to f(x). Section 4.5.
refutation
The testimony of a falsity.
runtime
The Python module truth.py, embedded in the compiler and imported by generated code. Section 10.5.
testimony
The tree of evidence carried by every truth. Section 5.
truth
Verity's type of truth values, with constructors verity and falsity. Section 3.2.
verity
The true constructor of truth. Its testimony is a witness.
witness
The testimony of a verity. Also the node kind produced by exists, naming the first element that satisfied the body.
