Appendix BGlossary

addpattern
A keyword that adds another case to a function defined by pattern matching, instead of replacing it. Cases are tried in definition order. See Section 6.2.
algebraic data type
A type described as a choice between several shapes, each with its own fields, such as a shape that is a Circle, a Rect or a Square. Built from data declarations.
because
An operator that attaches a claim, written in plain words, to a truth: p because msg. It renders as witnessed: msg or refuted: msg. See Section 3.6.
boolean blindness
The loss of information that happens when a computation's result is reduced to a single true/false bit.
counterexample
An element that refutes a forall claim. A falsity from forall reports the first one it finds.
data
A declaration of an immutable record type with named fields, such as data Rect(w, h).
erasure (testimony erasure)
The compiler pass that replaces truths whose testimony is never observed with plain Python booleans, so unused testimony costs nothing. See Section 8.6.
explain
The function testimony.explain, which renders a truth and its testimony as indented text.
falsity
The false value of type truth. A falsity carries a refutation.
lifting
Turning a plain Python bool into a Verity truth with minimal testimony. See Section 7.2.
observed
Said of testimony that something can look at, for example by passing the truth to explain, returning it, or storing it. Unobserved testimony can be erased.
partial application
Fixing some of a function's arguments to get a function of the rest, written f$(args).
pipe
The operator |>, which passes a value to a function: x |> f means f(x).
predicate
A function that returns a truth.
refutation
The testimony carried by a falsity: the evidence that a claim fails.
runtime
The Python module truth.py that compiled programs use for truths and testimony. It is embedded in the compiler and written out next to generated code.
testimony
The evidence a truth carries, either a witness or a refutation. It is structured as a tree.
truth
Verity's boolean type, with the two values verity and falsity.
verity
The true value of type truth. A verity carries a witness.
witness
The testimony carried by a verity: the evidence that a claim holds. Also the element that satisfies an exists claim.
