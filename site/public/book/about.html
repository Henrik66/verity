About These Docs

This is the reference documentation for the Verity programming language. It describes the language's syntax and semantics, the testimony model, the boundary with Python, the standard library, the command-line tool and the compiler's architecture. It is written to be precise rather than introductory: each section states rules, then gives examples.

Status of this document#

Verity is in early design and no implementation exists yet. This document describes the language the implementation is being built to accept. Every rule carries one of three markers:

MarkerMeaning
SettledFixed by the language specification or by an expected output in examples/. Changing it requires changing the spec.
ProposedA concrete design this document recommends. It has not yet been adopted by the spec and may change.
OpenAn unresolved question. Alternatives are listed where they are known.

A section-level marker applies to every rule in that section unless a rule carries its own marker.

Normative sources

In order of precedence:

  1. The language specification, CLAUDE.md in the repository root.
  2. The conformance examples, examples/*.ity, and their expected output, examples/*.expected. The rendering format of testimony is defined by these files.
  3. This document.

Where this document disagrees with a higher source, the higher source is correct and this document has a bug.

Notation#

Grammar

Syntax is given in a variant of EBNF:

FormMeaning
name ::= ...Defines the nonterminal name.
"text"A literal terminal: a keyword, operator or delimiter.
NAME, NEWLINEA token class produced by the lexer (all capitals).
a bSequence.
a | bAlternation.
[a]Optional.
a*, a+Zero or more, one or more.
(* ... *)Comment.

The complete grammar is collected in Appendix A.

Code and output

Verity source appears in blocks labeled verity, program output in blocks labeled output, generated Python in blocks labeled python, and shell commands, prefixed with $, in blocks labeled shell. Output blocks show exactly what the program prints, including the indentation of testimony.

verity
from testimony import explain

(3 > 5) |> explain |> print
output
falsity
  3 > 5: 3 <= 5

Scope#

This document does not teach programming or functional programming. Readers are assumed to know Python. Constructs that Verity takes unchanged from Python, such as literals, comprehensions, try and with, are listed but not re-specified. Their semantics are those of the corresponding Python construct.
