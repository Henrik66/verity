Section 6Statements

Verity's statements are Python 3.12's. This section specifies the one statement whose meaning differs, assert, and notes how the others interact with truths.

6.1 Simple statements#

Expression statements, assignment (including augmented and annotated assignment and unpacking), return, pass, break, continue, raise, del, global, nonlocal, import and type aliases are as in Python. Settled

6.2 The assert statement#

grammar
assert_stmt ::= "assert" expression ["," expression]

assert p evaluates p. Settled

  • If p is a truth or a bool (which is lifted) and is a falsity, it raises TestimonyError carrying the falsity (Section 3.6). If it is a verity, nothing happens.
  • If p is any other value, Python truthiness applies and a false value raises TestimonyError carrying a lifted falsity.
  • assert p, m means assert (p because m).
  • Unlike Python's, a Verity assert is never removed by python -O. Checks that explain themselves should not silently disappear.

An uncaught TestimonyError ends the program with the testimony on standard error, or as a JSON record with --json (Section 10.2). verity test reports it as a test failure.

verity
def withdraw(balance, amount):
    assert amount <= balance, f"the balance covers {amount}"
    return balance - amount

withdraw(50, 80)
output
withdraw.ity:2: TestimonyError
falsity
  refuted: the balance covers 80
    amount <= balance: 80 > 50

6.3 Function definitions#

def, lambda, decorators, default and keyword-only parameters, *args, **kwargs and annotations are as in Python. Settled A function that can return a truth is compiled in two versions so that unobserved testimony costs nothing (Section 5.10). This is invisible to callers: the function object is the evidence version.

verity
def in_range(x, lo, hi):
    return (lo <= x because f"{x} is at least {lo}") and (x <= hi because f"{x} is at most {hi}")

6.4 Classes and data classes#

class statements, inheritance, methods and @dataclass are as in Python. Settled Data classes are the recommended way to define plain data: @dataclass(frozen=True) gives immutable values with structural equality, a readable repr such as Circle(r=1), and positional patterns for match.

6.5 The match statement#

As in Python (PEP 634). Settled A case guard may be a truth, and its testimony is not built. A function that returns a truth from several case blocks returns whichever testimony that branch built.

verity
def is_square(shape):
    match shape:
        case Square(_):
            return verity because "it was built as a Square"
        case Rect(w, h):
            return w == h
        case _:
            return falsity because f"{shape} is a rectangle"

6.6 Conditionals and loops#

if/elif/else, while and for are as in Python. Settled Conditions may be truths or any Python value, with Python truthiness applying to non-truths. A condition is only branched on, so its testimony is not built (Section 5.9).

6.7 Imports#

import and from … import are as in Python. Settled Any importable Python module may be imported. The standard library modules (testimony, string_ops) are always importable and are the copies embedded in the compiler, even if a different version of verity-testimony is installed. Importing one .ity module from another compiles the imported module on demand. Whether a local module may shadow a standard library module is Open.

6.8 Other statements#

try/except/finally, with, async forms and yield are as in Python. Settled
