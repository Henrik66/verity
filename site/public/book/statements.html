Section 6Statements and Definitions

This section specifies Verity's statements and definitions. Statements not listed here are not part of the language. Those listed as "as in Python" have Python's syntax and semantics.

6.1 Simple statements#

  • Expression statements and assignment (=, augmented assignment, unpacking): as in Python.
  • return, pass, break, continue, raise, del, assert: as in Python. Proposed Whether a failing assert on a truth includes its testimony in the AssertionError message is Open.

6.2 Function definitions#

grammar
funcdef     ::= ["addpattern"] "def" NAME "(" [param_list] ")" ["->" expression] body
body        ::= "=" expression NEWLINE | ":" block
param_list  ::= param ("," param)* [","]
param       ::= NAME ["=" expression] | "*" NAME | "**" NAME | pattern

A def binds NAME to a function in the current scope. The body has two forms: Settled

  • Assignment form: def f(x) = expr. The function returns the value of expr. This is equivalent to def f(x): return expr.
  • Block form: def f(x): followed by an indented block, as in Python.

If every parameter is a plain name, the definition is an ordinary Python function. If any parameter is a pattern other than a plain name, the definition is a pattern-matching function.

verity
def square(x) = x * x
def hypotenuse(a, b) = (square(a) + square(b)) ** 0.5

def describe(n):
    kind = "even" if n % 2 == 0 else "odd"
    return f"{n} is {kind}"

6.3 Pattern-matching functions#

A pattern-matching function has an ordered list of cases, each a parameter list of patterns and a body. Settled

  • A def with pattern parameters creates a pattern-matching function with one case, replacing any previous binding of the name.
  • addpattern def f(...) appends a case to the pattern-matching function currently bound to f. If f is unbound, or is not a pattern-matching function, it is an error: a compile-time error when the compiler can determine this, otherwise TypeError at run time. Proposed
  • A call tries the cases in the order they were added. The first case whose patterns all match the arguments runs, with the pattern variables bound. If no case matches, the call raises MatchError.
verity
data Circle(r)
data Rect(w, h)

def area(Circle(r)) = 3.14159 * r ** 2
addpattern def area(Rect(w, h)) = w * h

def factorial(0) = 1
addpattern def factorial(n) = n * factorial(n - 1)

print(area(Rect(2, 3)), factorial(5))
output
6 120

6.4 Patterns#

grammar
pattern          ::= or_pattern ["as" NAME]
or_pattern       ::= closed_pattern ("|" closed_pattern)*
closed_pattern   ::= literal_pattern | capture | "_" | class_pattern
                   | sequence_pattern | "(" pattern ")"
capture          ::= NAME
class_pattern    ::= dotted_name "(" [pattern ("," pattern)* [","]] ")"
sequence_pattern ::= "[" [pattern ("," pattern)* [","]] "]"

Pattern semantics are those of Python's structural pattern matching (PEP 634): Proposed

  • A literal pattern matches an equal value. A capture binds a name, and _ matches anything without binding.
  • A class pattern C(p₁, …, pₙ) matches an instance of C whose fields, in declaration order, match p₁ … pₙ. data types support positional class patterns.
  • A sequence pattern matches a sequence of the same length whose elements match.

Mapping patterns, star patterns and keyword patterns in class patterns are Open.

6.5 Data declarations#

grammar
data_def ::= "data" NAME "(" [NAME ("," NAME)* [","]] ")" NEWLINE

data Name(f₁, …, fₙ) binds Name to a new class of immutable data values with fields f₁ … fₙ (Section 3.4). Settled Data declarations with a body (methods), default field values, type annotations and inheritance are Open.

6.6 The match statement#

grammar
match_stmt ::= "match" expression ":" NEWLINE INDENT case_block+ DEDENT
case_block ::= "case" pattern ["if" expression] ":" block

As in Python. The subject is evaluated once, then the cases are tried in order. The first case whose pattern matches and whose guard, if any, holds has its block executed. If no case matches, nothing happens and no exception is raised, unlike a pattern-matching function. Settled A guard may be a truth, and its testimony is not observed.

verity
def is_square(shape):
    match shape:
        case Square(_):
            return verity because "it was built as a Square"
        case Rect(w, h):
            return w == h
        case _:
            return falsity because f"{shape} is a rectangle"

6.7 Conditionals and loops#

if/elif/else, while and for are as in Python. Settled Conditions may be truths or any Python value, with Python truthiness applying to non-truths. The testimony of a condition is not observed (Section 5.4).

6.8 Imports#

import and from … import are as in Python. Settled Any importable Python module may be imported. The standard library modules (testimony, string_ops, list_ops) are always importable. Whether a local module may shadow a standard library module of the same name is Open. Importing one .ity module from another is Proposed. The compiler compiles the imported module and makes it importable under its file name.

6.9 Other Python statements#

try/except/finally, with, global and nonlocal are as in Python. Proposed class definitions, decorators, async forms and type aliases are Open.
