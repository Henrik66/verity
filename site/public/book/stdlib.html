Section 8Standard Library

The standard library consists of the modules testimony and string_ops. They are always importable from Verity, and they are the Python package verity-testimony. Module and function names are snake_case. Settled

In the signatures below, truthy means a Truth or a Python bool (which is lifted). Optional src and span arguments are filled in by the compiler; Python callers may pass them to get the same testimony a compiled program would.

8.1 Module testimony#

Rendering

explain(t: truthy, audience: str = "developer") -> str Settled

Return the text rendering of t defined in Section 5.4, for the given audience (Section 5.5): "verity" or "falsity" on the first line, followed by the indented testimony tree, without a trailing newline.

verity
from testimony import explain
print(explain(2 + 2 == 5))
output
falsity
  2 + 2 == 5: 4 != 5
to_json(t: truthy, audience: str = "developer") -> dict Settled

Return the testimony as a JSON-serializable dictionary in the schema verity.testimony/0 (Section 5.6).

to_bool(x: object) -> bool Settled

Return True for a verity and False for a falsity, discarding testimony. Any other value is converted by Python truthiness. Use it when passing truth values to Python code that requires a bool.

Building truths

verity, falsity Settled

The two truths with literal testimony. In Verity source these are keywords; from Python they are module constants.

all_of(*operands: truthy) -> Truth Settled

The accumulating conjunction (Section 5.2). Every operand has already been evaluated by the call. A falsity reports every failing operand under failed k of n:.

reason(id: str, message: str, hint: str | None = None) -> Reason Settled

A claim with a stable dotted ID and an optional hint, for use with because (Section 5.3). Raises ValueError if id does not match [a-z0-9_]+(\.[a-z0-9_]+)*.

secret(value) -> Secret, reveal(s: Secret) -> object Settled

Wrap a value so that testimony shows <secret>, and unwrap it (Section 5.7).

text(value: bool, sentence: str) -> Truth Settled

A truth whose testimony is a text node. Library predicates use it to state evidence in their own words, as string_ops.is_alnum does.

Python API for operators

These functions are what compiled code calls. Python code can call them directly to build the testimony that Verity syntax builds (Section 7.7). Settled

check(left, op: str, right, src: str | None = None, span=None) -> Truth | object

Apply the comparison op (one of == != < <= > >= in not in is is not). Returns a truth with a comparison node if Python's result is a bool, and Python's result unchanged otherwise. Secrets are unwrapped for the comparison and shown as <secret>. Without src, the node's source text is left op right with the captured reprs.

lift(value: bool, src: str | None = None, span=None) -> Truth

Lift a bool. A Truth is returned unchanged.

and_(*operands), or_(*operands)

Short-circuit conjunction and disjunction. Each operand is a truthy value or a zero-argument callable returning one; callables are called only when needed, which preserves short-circuiting. If an operand is neither, Python's semantics apply (Section 7.5).

not_(operand)

Negation.

because(t: truthy, m, span=None) -> Truth, also Truth.because(m)

Attach a claim. m is a string, a Reason, or a zero-argument callable returning one, called only when the testimony is built.

forall(iterable, body, name="x", src=None, body_src=None), exists(...)

Quantifiers. body is a one-argument callable returning a truthy value. src is the iterable's source text: when it is a plain name, positions render as src[i].

Configuration and errors

configure(max_repr: int = 80, max_children: int = 50, max_depth: int = 32) -> None Settled

Set the bounds of Section 5.8 for the current process. Arguments not given keep their current values.

class TestimonyError(AssertionError) Settled

Raised by a failing assert and by Truth.expect(). Attribute truth holds the falsity, and str(e) is explain(e.truth).

8.2 Class Truth#

The runtime class of truths. It is not normally named in Verity source: values are created by literals, comparisons and the operators in Section 4. Settled

bool(t), t.value

True for a verity, False for a falsity.

str(t), repr(t)

"verity" or "falsity".

t == u, hash(t)

Compare and hash by truth value only.

t.testimony

The root testimony node. Nodes are read-only objects with attributes kind, value, asserted, line, children (a tuple of nodes), span and the fields of their kind (Section 5.6).

t.because(m)

Same as t because m.

t.expect()

Return t if it is a verity. Raise TestimonyError if it is a falsity.

8.3 Module string_ops#

String predicates with character-level testimony. Settled

is_alnum(s: str) -> Truth

A verity if s is non-empty and every character is alphanumeric in the sense of Python's str.isalnum. Testimony, as a text node:

  • verity: every character of {repr(s)} is alphanumeric
  • falsity at the first offending character c at index i: {repr(c)} at index {i} is not alphanumeric
  • falsity for the empty string: '' is empty
verity
import string_ops
from testimony import explain
print(explain(string_ops.is_alnum("grace_hopper")))
output
falsity
  '_' at index 5 is not alphanumeric
is_alpha(s), is_digit(s), is_space(s), is_lower(s), is_upper(s)

Proposed Testifying counterparts of the other str.is* predicates, with the same testimony forms.
