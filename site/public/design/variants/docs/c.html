Testimony semantics

The node kinds, how each operator constructs them, how testimony.explain renders them, and when the compiler may omit them.

verity 0.09 settled3 proposed
quick lookverity run
explain(2 + 2 == 5)
falsity
  2 + 2 == 5: 4 != 5

5.1Node kinds testimony.nodes

A testimony is a tree of nodes. Each kind carries the data below.

comparison(src, left, rel, right)settled
From a op b. No children.
all(*children)settled
Verity from and. One child per conjunct.
because(message, value, child?)settled
From p because m.
counterexample(name, element, pos, child)settled
Falsity from forall.
lifted(src, value)proposed
A Python bool used as a truth.
counterexampleprimes.ity
forall p in primes, p % 2 == 1
falsity
  counterexample: p = 2 (primes[0])
    p % 2 == 1: 0 != 1

The child is the body's refutation, evaluated with p = 2.

5.2Conjunction testimony.and

For p₁ and … and pₙ, evaluated left to right:

and.falsity
If some pᵢ is a falsity, let k be the first. V = falsity, T = T(pₖ). Later operands are not evaluated.

and.verity
Otherwise V = verity and T = all(T(p₁), …, T(pₙ)), flattening nested all nodes.

validate.ityconformance
def valid_username(name) =
    (len(name) >= 3
        because f"{name!r} has at least 3 characters")
    and (len(name) <= 16
        because f"{name!r} has at most 16 characters")
    and (string_ops.is_alnum(name)
        because f"{name!r} is alphanumeric")
valid_username("al")stdout
falsity
  refuted: 'al' has at least 3 characters
    len(name) >= 3: 2 < 3
