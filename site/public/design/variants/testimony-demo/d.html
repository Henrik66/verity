The answer grows up top. The reason is underneath.

Every falsity keeps its roots. Dig in and you'll find the exact element and values that decided it.

primes = [2, 3, 5, 7, 11, 13]

(forall p in primes, p % 2 == 1)
    |> explain |> print

falsity ↓ dig for the reason

  1. falsitywhat came back up
  2. counterexample: p = 2 (primes[0])the element that broke the rule, and where
  3. p % 2 == 1: 0 != 1the values it saw

That's the whole output of explain, three lines, indented the way the roots branch. A plain boolean would have stopped at the first one.
